# Community Code of Conduct

## Our commitment

We want participation in RemoteAssist to be respectful, constructive, and safe. This applies to Issues, Pull Requests, code review, discussions, and other project spaces.

## Expected behavior

- Be considerate and communicate technical disagreement respectfully.
- Focus criticism on proposals and evidence, not on a contributor's identity or character.
- Accept correction and update claims when new evidence changes the result.
- Keep reports factual. Distinguish measured behavior from assumptions and mark unverified results clearly.
- Respect privacy. Do not publish credentials, screen contents, typed input, or private device information.
- Keep the product's visible-operation and user-authorization boundaries intact.

## Unacceptable behavior

- Harassment, threats, discrimination, sexualized attention, or personal attacks.
- Publishing another person's private information without permission.
- Posting credentials, tokens, screen captures, or input content belonging to another user.
- Encouraging unauthorized access, hidden control, credential theft, or evasion of security tools.
- Deliberately disrupting project infrastructure or testing systems without authorization.

## Enforcement

Project maintainers may edit or remove harmful content, close discussions, or restrict participation in project spaces when needed to protect contributors and users. Enforcement should be proportionate and explain the project-space action when doing so is safe.

The project has not yet designated a separate conduct-enforcement contact or appeal process. Do not use public project spaces to disclose a security vulnerability.
